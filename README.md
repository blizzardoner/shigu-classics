# 拾古 · 每日文言

面向初二至初三学生的本地优先文言文学习 PWA。设计沿用 Northstar English 的学习习惯：文章由学生手动切换、各篇进度独立保存、练习有解析，收藏的字词按间隔复习。

## 内容范围与重要说明

首版参考库共 26 篇，按常见统编八、九年级分组，不是上海现行官方目录或必考清单。上海不同入学年份、学校教材与教学顺序可能不同，须以孩子课本及教师要求核对。古文文字、通假字、断句也可能存在版本差异。

- 八上参考：三峡、答谢中书书、记承天寺夜游、与朱元思书、富贵不能淫、生于忧患死于安乐、愚公移山、周亚夫军细柳。
- 八下参考：桃花源记、小石潭记、核舟记、北冥有鱼、庄子与惠子游于濠梁之上、虽有嘉肴、大道之行也、马说。
- 九上参考：岳阳楼记、醉翁亭记、湖心亭看雪。
- 九下及拓展参考：鱼我所欲也、唐雎不辱使命、送东阳马生序、曹刿论战、邹忌讽齐王纳谏、陈涉世家、出师表。

原文为公版古代作品或常见课文节选。现代译文、讲解、练习为自主整理，供学习参考，不是出版社授权教材或官方试题。每篇保留原典参考链接，未访问核实的链接有注明。

## 功能

- 全文原译对照，按句/短段展开译文，可一键展开全部。
- 重点字词、读音、例句，以及语法、主旨和表达考点。
- 选择题小测与逐题解析，错题加入复习本；复习答对后移出。
- 理解表达草稿自动保存，提供参考思路。
- 表达检查只统计字数、主题词，不是 AI、语义批改或教师评分。
- 背诵填空，忽略标点空格、保留字词差异核对。
- 收藏字词按 1 / 3 / 6 / 12 / 24 / 30 天间隔复习。
- 学习天数、完成篇目、小测正确率、阅读记录与 JSON 导出。
- 白底移动端界面、离线全文、iPhone 主屏幕图标。

## 隐私与完成条件

无广告、第三方字体、追踪器、账号服务、AI 调用或学生数据上传。学习记录存于浏览器 localStorage，清理站点数据会删除它们。导出文件可保管留档；首版没有导入入口。

完成一篇须打开课文、交齐选择题、写满至少 30 字并命中至少两个提示主题词。这里只记录学习步骤，不表示全部答对或掌握；写作准确性须自己对照原文或请教师复核。背诵填空属于可选强化，不参与完成条件。

## 本地运行

需要 Node.js；生产 App 本身没有第三方运行时依赖。

```
npm install
npm test
npm run build
npm run serve
```

打开 http://127.0.0.1:4186/ 。构建产物在 `dist/`，服务仅绑定本机。`npm run build` 自动收集所有内容模块进入版本化离线缓存。

`npm run qa` 使用 Windows 已安装的 Microsoft Edge 进行真实手机尺寸浏览器测试；也可设 `BASE_URL` 验证发布网址。`scripts/icons.py` 是重新生成图标的可选辅助，依赖 Pillow 及 Windows 宋体；仓库已包含生成好的 PNG，正常构建无需 Python。

## iPhone 安装边界

需先将 dist 发布到 HTTPS 静态托管，支持项目子路径。然后 iPhone Safari 打开正式链接 → 分享 → 添加到主屏幕。localhost 测试不等于已发布或已在真实 iPhone 安装。本地服务也不能用手机上的 localhost 访问。

首次联网打开后服务工作线程缓存全文、脚本、样式与图标，之后可离线读文和练习。浏览器自动回收缓存、手动清除数据或尚未完成首轮缓存时仍需联网。
